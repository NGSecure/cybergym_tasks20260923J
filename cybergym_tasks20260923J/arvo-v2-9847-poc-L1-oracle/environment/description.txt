libmagic's JSON content-detector suffers a 1-byte heap-buffer-overflow read while scanning a JSON object. Root cause: after successfully parsing a member's value, the object-parsing loop unconditionally dereferences the very next input byte to check whether it is a comma or a closing brace, without first checking whether the value's parse already consumed every remaining byte of the buffer — when it did, that dereference reads one byte past the end of the heap allocation holding the scanned data.
