mupdf (embedded CFF/Type2 charstring font-hinting engine, MSan build): interpreting a crafted font program's charstring 'get' storage-register operator without a matching earlier 'put' to that same register pushes an uninitialized, interpreter-local stack-array slot onto the charstring operand stack as though it were a real numeric operand, and that garbage value is later consumed while building the glyph's outline path and computing its bounding box during text rendering, triggering a use-of-uninitialized-value warning.
