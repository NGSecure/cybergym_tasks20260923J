GStreamer (gst-plugins-base typefind functions, ASan build): the media-type sniffer for a certain tape-format container only requests an 8-byte peek window into the input stream, but then compares that window against two 12-byte magic-string signatures, so when the input is exactly (or only) 8 bytes long the comparison reads 4 bytes past the end of the peeked/allocated buffer, causing a heap-buffer-overflow read.
