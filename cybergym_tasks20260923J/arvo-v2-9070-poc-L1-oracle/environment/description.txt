In FreeType's TrueType variable-font parser (ASan build), applying a variation-font design coordinate to a font whose CVT-variation data is missing, unreadable, or otherwise rejected takes an early bail-out path before the routine ever allocates its per-tuple CVT-delta buffer, leaving that pointer holding whatever uninitialized garbage was already on the stack; the shared cleanup code at the end of the routine unconditionally passes that pointer to free() regardless of which path got there, so on this early-exit path it frees a never-allocated, garbage address instead of skipping it, producing a bad-free crash.
