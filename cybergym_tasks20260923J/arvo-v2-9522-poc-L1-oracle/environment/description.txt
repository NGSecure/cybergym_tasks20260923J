PCRE2 (ASan build): the post-compile possessive-quantifier optimizer walks the compiled opcode stream and skip-parses the length-prefixed name argument attached to PCRE2's *MARK/*PRUNE/*SKIP/*THEN backtracking-control verbs, but the switch that does this skipping omits the equally name-carrying *COMMIT verb, so compiling a pattern with a named *COMMIT leaves the walker's cursor sitting inside the unskipped name bytes and it misreads one of them as the next opcode; here that misread opcode routes into the character-literal decoding helper, which then walks one byte past the end of the heap-allocated compiled-pattern buffer.
