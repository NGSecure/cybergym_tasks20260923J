GraphicsMagick's TIFF coder trips a MemorySanitizer use-of-uninitialized-value warning while decompressing a ZIP(Deflate)-compressed strip in a TIFF image. Root cause: libtiff's ZIP decoder feeds a corrupted/truncated compressed strip into zlib's decompression engine, and the engine's stream-resync error-recovery path ends up reading window bytes that were never initialized for that strip.
