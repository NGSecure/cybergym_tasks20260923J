libaom's AV1 decoder keeps a persistent per-block mode-info grid; each block's segment id selects a row in a fixed 8-entry per-segment feature table, but a per-frame syntax-ordering flag can make the decoder consult that segment id (to test a segmentation feature bit) before the current block's own segment-id syntax element has actually been parsed for this frame, so the lookup reads whatever value is left over in the reused grid slot from an earlier block or frame instead of one validated for the current block; that stale, unbounded value is then used directly to index the fixed-size feature table with no range check, so a bitstream that reaches this "skip decided before segment id" path with an out-of-range carried-over value triggers an index-out-of-bounds read.
