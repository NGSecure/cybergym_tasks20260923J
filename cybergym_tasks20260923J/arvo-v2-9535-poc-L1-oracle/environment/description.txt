PCRE2 (ASan build): the same post-compile opcode walker that skip-parses the length-prefixed name argument of *MARK/*PRUNE/*SKIP/*THEN also omits the name-carrying *COMMIT verb from that skip logic, so a pattern using a named *COMMIT again leaves the cursor parked inside the unskipped name and a name byte gets misread as the next opcode; here that misread instead falls into the walker's own character-class handling, which derives a follow-up pointer from the corrupted position and dereferences an address far outside the compiled-pattern allocation, aborting on a wild, unmapped read rather than a narrow one-byte overrun.
