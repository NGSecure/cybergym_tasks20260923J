ImageMagick (MSan build): a LABEL image whose caption text embeds an FX (image-calculator) percent-escape referencing "the current pixel" is evaluated against the same kind of one-pixel placeholder image the label/property text interpreter fabricates whenever no real source image is attached yet. Evaluating the expression has to interpolate a pixel value out of that placeholder's own pixel cache (virtual-pixel lookup feeding a pixel interpolation/blend step), but because the placeholder's pixel storage was allocated without ever being given a defined color, the interpolation reads straight from the unfilled buffer. MemorySanitizer flags this as a use-of-uninitialized-value inside the FX expression evaluator itself, before the computed channel value is even handed back to the caller.
