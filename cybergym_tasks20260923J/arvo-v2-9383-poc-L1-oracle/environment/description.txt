Skia (ASan build): drawing text through the GPU (Ganesh) canvas path uses a single internal glyph-run builder buffer to stage each draw call's paint, and starting the next glyph run explicitly destroys that buffer's paint copy in place before reusing the memory — including releasing the color filter the paint owned — while the earlier draw's GPU text-color computation is still reading that filter object, producing a heap-use-after-free read.
