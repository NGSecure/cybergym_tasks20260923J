This crash arises in the code that lowers a vector path mini-language (move, line, curve, and close-path commands) into an internal array of drawing primitives that is built incrementally and grown on demand as more coordinate data is consumed; a running numeric offset tracks how much of that array has been filled so far, and a separate pointer is kept to mark where the current sub-figure (the run of commands since the last move or close) began. When a new move command is encountered, the code decides whether the previous sub-figure needs to be closed off and have its point count recorded by comparing the current write cursor against that saved start-of-figure pointer for simple pointer (in)equality, instead of comparing the numeric offsets that were recorded when the sub-figure began versus the offset reached now. That distinction matters because the underlying array can be reallocated to a larger block partway through parsing once the consumed offset approaches the array's current capacity; once such a growth happens, any pointer computed relative to the old block, including the saved start-of-figure pointer and the write cursor derived from it, no longer denotes a valid location inside the possibly-relocated live block, even though the numeric offsets those pointers were meant to represent remain perfectly well defined and comparable. A path containing a sequence of moves with enough coordinate pairs between them to push the consumed offset across a growth threshold one or more times therefore leaves the finalize-previous-sub-figure logic holding a start-of-figure pointer, and a base value used to re-derive it, that both reference a superseded allocation rather than the current one. The subsequent write that stores the just-closed sub-figure's point count then lands through that stale pointer, far outside any buffer the process actually owns, producing a wild out-of-bounds write rather than a small adjacent-byte overrun, and an immediate fault under memory-checking instrumentation, since the target address is essentially an arbitrary leftover value rather than a location merely a few bytes past a real allocation.
