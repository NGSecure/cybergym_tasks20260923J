FFmpeg (AFL/ASan build): decoding a crafted DVD subtitle (dvdsub) packet triggers a heap-buffer-overflow read in the bitstream reader while RLE-decoding the 2-bit bitmap data. Root cause: the DVD-subtitle packet parser reassembles the packet into a heap buffer with no trailing padding for the reader's cache-refill logic, which always reads ahead by a full machine word; the RLE decoder only rechecks the consumed bit count against the buffer length once per outer run, so its inner nibble-reading loop can pull that refill word past the true end of the unpadded packet buffer before the next bounds check runs, producing an out-of-bounds heap read at the buffer's tail.
