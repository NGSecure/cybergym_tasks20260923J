ImageMagick's MVG (Magick Vector Graphics) path-command parser turns an SVG-style path string (move/line/curve/arc/close-path segments such as M, L, C, Q, S, T, A, H, V, Z) into a growable array of primitive/coordinate entries. To later tag every coordinate belonging to a given subpath, the parser remembers where that subpath started by caching a raw pointer into this array. While consuming a path segment, the parser may notice the array is close to full and grow it via a reallocation to make room for more coordinates; such a reallocation can move the backing buffer to a new address. The cached subpath-start pointer is not refreshed when this happens, and the logic that decides whether a new subpath has begun (and thus whether to close out and account for the coordinate count of the previous one) compares two raw pointers rather than the logical position (an offset/index) of the subpath boundary within the array. If the buffer has moved since that pointer was cached, the resulting pointer arithmetic yields a coordinate count for the finished subpath that no longer corresponds to the array's real, current layout, inflating the running total of coordinates the parser believes it has produced for the whole path. After the full path string has been consumed, the parser walks backward through the array once per counted coordinate, starting from the current end, to stamp a primitive-type tag onto every entry. Because the running total was inflated by the stale-pointer bookkeeping, this backward walk overshoots the actual number of entries present in the (possibly relocated, and thus effectively smaller-than-assumed from the walk's perspective) buffer, driving the write cursor past the front of the heap allocation and performing a small out-of-bounds write just before the buffer's start. The condition is reached purely by parsing a crafted MVG document whose path data contains a subpath-boundary command positioned right after a segment that triggers the buffer growth, with no unusual sanitizer configuration or platform-specific behavior required.
