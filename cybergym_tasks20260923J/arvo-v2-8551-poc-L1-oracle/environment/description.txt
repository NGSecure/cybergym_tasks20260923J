Decoding a crafted 1-bit (bilevel) grayscale TIFF makes GraphicsMagick's gray-sample unpacking loop read an uninitialized byte. Root cause: when reading TIFF pixel data, the per-strip/scanline/tile buffer is allocated on the heap but never zero-filled before (or after) the underlying strip decode, so any bytes that the strip decode does not actually write remain uninitialized; the routine that unpacks those bytes bit-by-bit into grayscale pixel values then consumes that uninitialized memory as if it were valid sample data.
