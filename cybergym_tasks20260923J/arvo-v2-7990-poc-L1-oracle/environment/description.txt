ImageMagick (ASan build): while pinging a TIFF image, the routine that extracts EXIF camera/metadata tags asks the underlying TIFF library's generic per-tag value accessor for each recognized tag, treating most of them as fixed-width scalars (e.g. a single 16-bit field) and reserving only a matching small variable on the stack to receive each one. Root cause: for tags that fall outside the library's small set of built-in, hard-coded field descriptors, that accessor decides how much data to hand back to the caller based on the number of value entries it actually parsed out of the file for that tag, rather than on the field's declared fixed width; when a crafted directory entry claims more than one value for a tag the caller expects to be a lone scalar, the accessor instead writes back a full pointer-sized value, several times wider than the small stack variable reserved for it, overflowing adjacent stack memory.
