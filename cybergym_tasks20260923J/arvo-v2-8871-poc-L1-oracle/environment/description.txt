ImageMagick's HEIC/HEIF decoder (the bundled libheif library, ASan build): reconstructing a grid-tiled HEIC image from a malformed file triggers a negative-size-param crash. The image is declared as a mosaic of separately HEVC-coded tiles that are decoded concurrently and then stitched into one final pixel buffer by copying each decoded tile's rows into their proper position. The crafted file's grid metadata is inconsistent with the tiles actually present — a tile ends up placed so that the portion of it meant to be copied into the destination image extends past the declared overall image extent — so the per-row copy length, computed from how much of the destination row remains at that tile's offset, underflows into a negative value before being handed to a memory-copy routine, which AddressSanitizer flags as a negative-size-param abort rather than an out-of-bounds read/write.
