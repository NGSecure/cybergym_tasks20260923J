MuPDF (MSan build): while repairing a malformed PDF, an embedded JBIG2 image stream reaches the arithmetic generic-region decoder for a page context that never went through a page-info segment first, so the decoder reads that page's geometry/striping state from a page-table slot that was heap-allocated but never given safe default values, triggering a use-of-uninitialized-value warning when that unset state is used to decide how the region should be clipped.
