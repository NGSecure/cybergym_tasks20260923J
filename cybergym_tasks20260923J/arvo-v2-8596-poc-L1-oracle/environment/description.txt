GraphicsMagick (UBSan build): reading an MNG image's DEFI chunk, the object identifier is a 16-bit value taken straight from the chunk payload; an over-large id is clamped to the size of the internal per-object bookkeeping array instead of to its last valid index, so the clamped id is used as an array subscript one past the end of a fixed-size table, triggering an index-out-of-bounds access.
