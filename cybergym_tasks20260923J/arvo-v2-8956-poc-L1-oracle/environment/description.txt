In Skia's Skottie (Bodymovin/Lottie) animation JSON parser (MSan), when a point's x or y coordinate is given as an empty JSON array (a format variant some Bodymovin exporters use), the code that unwraps such single-element arrays checks only that the value is an array before reading its first element, without checking that the array actually has one; for a zero-length array this indexes past its (empty) storage into adjacent, not-yet-written memory in the arena, and the resulting garbage object's type tag is then read to decide how to interpret it, triggering a use-of-uninitialized-value read.
