MuPDF (JBIG2 image decoder, MSan build): decoding an embedded JBIG2 text region allocates a fresh bitmap buffer with a plain heap allocation that is never zero-filled, and when the region's symbol/Huffman table data is malformed the decoder does not fully populate every byte of that bitmap before it is composited into the page image, so the leftover uninitialized bytes are later read as pixel data while unpacking the image tile for rendering, triggering a use-of-uninitialized-value warning.
