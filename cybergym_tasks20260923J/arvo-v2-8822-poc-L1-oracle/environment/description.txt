ImageMagick (ASan build): parsing a crafted MVG (Magick Vector Graphics) drawing script triggers a heap-buffer-overflow read inside the routine that grows the array holding parsed drawing-primitive records as more primitives are appended. When the array's tracked capacity would be exceeded, the routine allocates a larger block and copies the previously-stored primitives into it, but the copy's byte length comes from a capacity value that is computed in primitive-slot units for the "is there still room" check yet reused unconverted as a raw byte count for the copy itself. An MVG input engineered to advance the primitive count through a particular sequence of insertions makes that mismatched value describe more bytes than the old, smaller block actually contains by the time the copy runs, so the copy reads past the end of the old allocation into adjacent heap memory instead of stopping within it.
