GraphicsMagick (MSan build): the same DPX-decoding gap that leaves part of a pixel-cache scanline unfilled when an image element list doesn't actually supply one of the red/green/blue channels (the coder's channel-completeness check runs only after decoding has already populated the cache) also surfaces when the decoded image is fed straight into the noise-reduction "enhance" filter rather than re-encoded: the filter copies a neighborhood of pixels into its own working cache view and reads component values from that never-initialized channel while computing each output pixel, triggering a use-of-uninitialized-value warning.
