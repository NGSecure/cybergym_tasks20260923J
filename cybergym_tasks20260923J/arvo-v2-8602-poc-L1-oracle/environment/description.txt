A crafted DICOM (DCM) image with RGB or planar-RGB pixel data triggers a use of uninitialized heap memory in GraphicsMagick's DCM decoder during a post-decode pixel-value rescale pass. Root cause: the RGB decode path writes pixel color components directly into a newly allocated pixel buffer but leaves the image's storage-class flag set to its earlier palette/indexed state from a prior parsing stage, so the later rescale pass follows the indexed-pixel branch and reads a per-pixel index array that was never populated for that buffer.
