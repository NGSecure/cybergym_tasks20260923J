MuPDF (MSan build): while repairing a malformed PDF, a JBIG2 symbol dictionary that is Huffman-coded with an MMR-compressed collective bitmap crashes with a SEGV read because the check that validates the encoded bitmap's declared byte size against the bytes remaining in the segment does an unsigned subtraction that can underflow, so an over-large declared size is accepted as valid and the MMR bitmap reader ends up being handed a data pointer and length that run past the end of the segment buffer.
